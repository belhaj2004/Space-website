#  Space Tourism Website

A multi-page space tourism website built with HTML, CSS, JavaScript, and React — featuring destinations, crew profiles, and spacecraft technology.

 **Live Site:** [space-info-by-adib.netlify.app](https://space-info-by-adib.netlify.app)

---

## About

This project is a fully responsive space tourism website inspired by the Frontend Mentor challenge. It presents an immersive UI experience with four sections: a home landing page, destination guide, crew profiles, and technology overview. Data is loaded dynamically from a JSON file, and the site is deployed via Netlify.

---

## Pages

| Page | Description |
|------|-------------|
| **Home** | Landing page with an "Explore" call-to-action |
| **Destination** | Info on Moon, Mars, Europa, and Titan — with distance and travel time |
| **Crew** | Profiles of Commander, Mission Specialist, Pilot, and Flight Engineer |
| **Technology** | Overview of Launch Vehicle, Spaceport, and Space Capsule |

---

## Features

- Multi-page navigation with responsive layout
- Dynamic content loaded from `data.json`
- Responsive design for desktop, tablet, and mobile
- Custom Google Fonts and background imagery per page
- Deployed and live on Netlify

## How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/belhaj2004/Space-website.git
```

### 2. Install dependencies

```bash
cd Space-website
npm install
```

### 3. Start the development server

```bash
npm start
```

The app will open at `http://localhost:3000`
